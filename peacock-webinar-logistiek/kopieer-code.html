Vul de webinargegevens in

2

Kopieer de code

Werkt de knop niet? Klik in het donkere vak, druk op Ctrl+A (Mac: Cmd+A) en daarna op Ctrl+C (Mac: Cmd+C).

3

Plak de code in WordPress

  1. Ga naar Pagina's → Nieuwe pagina en kies een sjabloon met volledige breedte, zonder zijbalk.
  2. Klik op + en kies het blok Aangepaste HTML (Custom HTML).
  3. Plak de code (Ctrl+V) en klik op Voorbeeld.
  4. Gebruik je Elementor? Kies dan de HTML-widget. Klassieke editor? Plak in het tabblad Tekst, niet in Visueel.

Je moet Beheerder zijn in WordPress, anders haalt WordPress een deel van de code weg.
